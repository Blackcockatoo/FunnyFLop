# B$S Ritual — Vite Project

## Run
```bash
npm i
npm run dev
```
Open the URL Vite prints (e.g., http://localhost:5173).

## Build
```bash
npm run build
npm run preview
```

This project wires your uploaded components:
- `PrimeCommandCenter.jsx` (root shell + tabs)
- `RitualDrop.jsx` (drop mini-game)
- `VaultVisualization.jsx` (entropy/xor/tail charts)

Edit `src/PrimeCommandCenter.jsx` to tweak tabs and defaults.
